# PhysioNet/CinC Challenge 2012 data (case C)

The raw data are not redistributed here. Download from PhysioNet
(https://physionet.org/content/challenge-2012/): `set-a.tar.gz` (4,000 ICU stays, one
text file per stay) and `Outcomes-a.txt`. Extract so that this folder contains:

    data/set-a/132539.txt ...
    data/Outcomes-a.txt

Cite: Silva I, Moody G, Scott DJ, Celi LA, Mark RG. Predicting in-hospital mortality of
ICU patients: the PhysioNet/Computing in Cardiology Challenge 2012. Comput Cardiol 2012;39:245-248.
